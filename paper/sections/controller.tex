\section{Adaptive Runtime Controller}
\label{sec:controller}
% Role: ownership/evidence boundary; the owner supplies the eventual method.
The runtime must select budgets using only signals available at decision time
and distinguish online self-check acceptance from the offline quality predicate
in Section~\ref{sec:quality}. This working manuscript does not yet specify or
evaluate a completed controller. Its owner-reviewed policy, retry/fallback
rules, and reuse implementation are required before this section can describe
an implemented adaptive method.
